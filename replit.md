# IdleRestaurant - Unity Mobile Game

## Project Overview
Unity 2019.2.21f1 idle restaurant mobile game ("IdleGame1 / IdleRestaurant_Src").
Targets Android (Google Play) and iOS (Apple App Store).
Integrations: Firebase Analytics, Google Mobile Ads, Unity Ads, Spine animations, Unity IAP, Parse SDK.

**Note:** This project cannot be run directly on Replit. Unity requires the Unity Editor (desktop app) to build and run. Replit is used here for code review, editing, and version control.

## User Preferences
- Every change, no matter how small, must be immediately pushed/committed to the repository.
